# Flowmax 操作手册

更新日期：2026-07-23  
适用对象：第一次使用 Flowmax 创建 Research Agent 与 PM Agent 的用户

## 1. 产品结构

登录后，顶部主导航有三个核心入口：

| 页面 | 作用 | 主要操作 |
|---|---|---|
| AI 策略 | 浏览公开策略与实时排行榜 | 看最新决策、关联分析师、30 日盈亏、胜率、关注、详情、Fork |
| 分析师 | 浏览 Research Agent 的最新观点 | 按专精筛选、按币种查看、对照做多/做空观点、关注分析师 |
| 我的 AI | 管理自己创建或 Fork 的 Agent | 查看策略/分析师列表、运行状态、模拟盘、决策周期、模型与信号源 |

首页策略卡会展示：策略名称、币种分类、模型、最新决策、所用分析师、30 日盈亏、胜率、关注数，以及“详情”“Fork”操作。

“分析师广场”按做多与做空分栏显示实时观点。每条观点会标明分析师、交易标的、发布时间和结论摘要。

“我的 AI”分为“策略”和“分析师”两个标签。策略列表会显示运行状态、模拟盘/实盘、决策周期、模型和分析师数量。

## 2. 创建 Research Agent

入口：`分析师` → `创建分析师`

界面共有三步：

### 第 1 步：基础设置

1. 填写分析师名称。
2. 选择市场。目前界面可用市场为 `Crypto`，其他市场可能显示为未开放。
3. 用一句话填写分析方向。
4. 选择 LLM。当前界面默认模型为 `gemini-3-flash-preview`。
5. 选择分析类型：
   - `Capital Flow Analysis`：资金流分析。
   - `Investment Research`：投资研究。
   - `Quantitative Analysis`：量化分析。
6. 点击“继续”。

推荐示例：

- 名称：`Crypto·资金费率与 OI 风险雷达`
- 市场：`Crypto`
- 分析方向：`跟踪资金费率、持仓量（OI）与爆仓变化，交叉验证拥挤交易和潜在反转风险。`
- 分析类型：`Capital Flow Analysis`
- 可见性：先设为私有

### 第 2 步：分析师提示词

提示词要同时写清楚研究目标、必用数据源、输出格式与禁止事项。推荐模板：

```text
研究目标：识别 BTC 永续合约中的拥挤交易、减仓与潜在反转风险。

研究步骤：
1. 对比资金费率当前值、历史分位与变化速度。
2. 检查持仓量（OI）与价格同向或背离关系。
3. 结合多空爆仓数据判断杠杆出清方向。
4. 对相互冲突的信号做交叉验证，不强行给出单边结论。

【必用数据源】资金费率、持仓量（OI）、多空爆仓
【输出格式】结论、信号方向、置信度、关键价位、风险提示

仅允许使用上文【必用数据源】列出的数据源；
不得调用未列出的其他数据源；
不得编造数据；
数据缺失时必须明确说明。
```

### 第 3 步：可见性与上线

1. 检查名称、市场、模型、分析类型和提示词。
2. 首次验证建议选择“私有”。
3. 提交后等待部署完成。
4. 回到“我的 AI” → “分析师”，确认它已出现并能持续发布观点。

## 3. 创建 PM Agent

入口：`AI 策略` 或 `我的 AI` → `创建策略`

界面共六题，系统会把选择实时合成为提示词、风控规则与分析师组合。

### Q1：目标

- 稳健保值：低频，控制回撤优先。
- 波段交易：中频，捕捉支撑阻力区间波动。
- 趋势跟踪：中频，突破后顺势跟进。
- 套利对冲：低频，关注资金费率或基差。

### Q2：风格

- 保守：1x 杠杆、总仓约 30%、单币约 15%。
- 平衡：1–3x 杠杆、总仓约 50%、单币约 20%。
- 激进：1–5x 杠杆、总仓约 80%、单币约 25%。

首次使用建议选“保守”。

### Q3：标的

- 主流币：界面示例包含 BTC、ETH、SOL 永续合约。
- 扩展主流：更广的主流标的组合。
- 自定义组合/交给 AI 挑选：当前界面可能显示“即将推出”。

### Q4：频率

- 每 15 分钟：中频，数据更新更及时。
- 每 1 小时：低频，噪声更少。

如果希望持续看到新数据，建议明确选择 15 分钟，不要依赖隐式默认值。

### Q5：止盈止损

- 见好就收：止盈 +2%，止损 -1.5%。
- 纪律为王：止盈 +5%，止损 -3%。
- 钻石手：止盈 +12%，止损 -8%。

保守测试建议选择“纪律为王”，并保持硬止损。

### Q6：生成策略

界面会显示已组合的目标、风格、标的、频率、止盈止损和分析师数量。点击“生成策略”后，系统会合成策略提示词与风控规则，并进入最终雇佣/上线阶段。

首次创建建议：

- 名称：`保守·稳健保值 (BTC)`
- 标的：`BTCUSDT`
- 目标：`steady`
- 风格：`conservative`
- 决策周期：15 分钟
- 风控：硬止损
- 可见性：私有
- 交易环境：模拟盘
- 绑定分析师：`Crypto·资金费率与 OI 风险雷达`

## 4. 创建后检查

PM Agent 创建成功后立即检查：

- Scheduler 显示为运行中。
- 决策周期是 15 分钟（900000 ms），不是意外的 1 小时。
- 名称、币种、目标和风险档位正确。
- 使用的是模拟盘凭证。
- 持仓数量正常，没有持续堆仓；健康策略通常保持少量持仓。
- Research Agent 已正确绑定并持续提供信号。

## 5. 日常查看与运维

在“我的 AI”中进入策略详情，重点查看：

- 当前运行阶段：空闲、初始化、研究、决策或完成。
- 最新决策及使用的分析师观点。
- 每日盈亏汇总。
- 逐单盈亏。
- 当前持仓与杠杆。
- Scheduler 是否运行。
- 决策周期是否符合预期。

修改提示词、风险档位或决策周期后，需要确认 Agent 已重新加载新配置。若停止 Scheduler、删除 Agent 或切换到真实交易，先记录原配置并进行二次确认。

## 6. 常见问题

| 问题 | 处理建议 |
|---|---|
| 分析师创建后没有观点 | 检查部署是否完成、提示词是否引用了有效数据源、数据是否缺失 |
| 策略长时间不更新 | 检查 Scheduler 和决策周期；建议显式设置为 15 分钟 |
| 选择 Crypto 时提交失败 | 确保市场值写为 `Crypto`，注意首字母大写 |
| MATIC 行情不可用 | 改用 `POLUSDT` |
| 改配置后仍执行旧逻辑 | 停止 Scheduler，保存配置，再重新启动 |
| 持仓数量异常增多 | 立即停止 Scheduler，检查提示词中的仓位纪律和硬止损 |

## 7. 安全原则

- 先私有、后公开。
- 先模拟盘、后真实交易。
- 不在聊天、文档或截图中共享 JWT、API Key、交易所密钥和验证码。
- 每个 PM Agent 使用独立的模拟盘凭证。
- 真实交易前必须设置硬止损，并再次确认杠杆、总仓和单币上限。
- Flowmax 的研究与策略输出不构成投资建议。
