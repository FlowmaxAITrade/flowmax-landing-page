# Flowmax 主站操作指南与客服 FAQ

更新日期：2026-07-23  
适用对象：第一次使用 Flowmax 的用户、运营及客服人员  
说明：界面与规则可能随版本更新；涉及价格、Credits 和真实交易的内容，以产品页面实时显示为准。

## 1. 先了解 Flowmax

Flowmax 的核心对象分为两类：

| 对象 | 作用 | 可以理解为 |
|---|---|---|
| Research Agent / 分析师 | 持续读取市场数据、完成指定研究并输出观点 | 负责“研究和提供信号” |
| PM Agent / 策略 | 组合分析师信号、策略目标和风险规则，生成交易决策 | 负责“决策、风控和执行” |

最简单的使用路径是：

1. 注册并登录；
2. 浏览公开的分析师与策略；
3. 查看详情，理解它做什么、怎么运行；
4. Fork 一个已有 Agent，或从零创建自己的 Agent；
5. 优先用私有与模拟方式验证；
6. 在“我的 AI”中持续查看状态、决策、持仓和表现。

## 2. 注册与登录

### 2.1 注册

1. 打开 Flowmax 主站；
2. 点击“注册”或“Sign up”；
3. 输入页面要求的邮箱及其他信息；
4. 阅读并同意相关条款；
5. 按提示完成邮箱验证；
6. 返回登录页并登录。

### 2.2 登录

1. 输入注册邮箱；
2. 输入密码或按页面提供的登录方式操作；
3. 登录后，确认右上角出现个人账户入口。

### 2.3 收不到验证码或验证邮件

- 检查垃圾邮件、推广邮件和邮件拦截规则；
- 确认邮箱拼写无误；
- 等待 1–3 分钟后重新发送；
- 不要连续快速点击，以免触发发送频率限制；
- 仍未收到时，向客服提供注册邮箱、发生时间和页面截图。不要提供密码或验证码。

### 2.4 忘记密码

在登录页点击“忘记密码”，通过注册邮箱完成重置。客服不会索要用户密码、验证码、私钥或交易所 API Secret。

## 3. 主站有哪些页面

| 页面 | 主要作用 | 常用操作 |
|---|---|---|
| AI 策略 | 浏览公开策略与表现信息 | 查看详情、关注、Fork |
| 分析师 | 浏览 Research Agent 的市场观点 | 按方向或标的筛选、关注、查看详情 |
| 我的 AI | 管理自己创建或 Fork 的 Agent | 查看状态、启动、暂停、编辑或删除 |
| Credits / 账户 | 查看余额及账户相关信息 | 充值、查看余额与消耗记录 |

策略卡片可能展示策略名称、市场或币种、模型、最新决策、关联分析师、收益表现、胜率、关注人数等信息。所有表现数据都应结合统计周期和风险水平理解，历史表现不代表未来结果。

## 4. 浏览分析师和策略

### 4.1 查看 Research Agent

进入“分析师”页面后：

1. 使用页面提供的市场、方向或标的筛选；
2. 打开感兴趣的分析师详情；
3. 查看它的分析方向、数据类型、最新观点、发布时间和历史输出；
4. 确认该分析师是否符合你的策略目标；
5. 需要持续查看时点击“关注”。

不要只根据一条观点判断分析师质量。建议观察多个市场周期，并确认它是否清楚说明数据不足、观点冲突和风险条件。

### 4.2 查看 PM Agent

进入“AI 策略”页面后：

1. 浏览公开策略；
2. 打开“详情”；
3. 查看策略目标、风险风格、交易标的、决策频率、关联分析师和最新决策；
4. 查看收益、回撤、胜率等表现时，确认统计周期和口径；
5. 确认符合自己的风险偏好后，再关注或 Fork。

## 5. 创建 Research Agent（分析师）

入口：`分析师 → 创建分析师`

界面通常分为三步。

### 第 1 步：基础设置

1. **名称**：使用能说明研究方向的名称；
2. **市场**：选择当前已开放的市场；界面未开放的选项无法创建；
3. **分析方向**：用一句话写明要研究什么；
4. **模型**：从页面当前可用的模型中选择；
5. **分析类型**：按目标选择资金流、投资研究或量化分析等类型；
6. 点击“继续”。

示例：

- 名称：`Crypto · 资金费率与 OI 风险雷达`
- 市场：`Crypto`
- 分析方向：`跟踪资金费率、持仓量与爆仓变化，识别拥挤交易和潜在反转风险`
- 分析类型：`Capital Flow Analysis`
- 可见性：第一次建议设为“私有”

### 第 2 步：编写提示词

一份可用的提示词应包括：

- 研究目标；
- 必须使用的数据；
- 分析步骤；
- 输出格式；
- 数据缺失时的处理方式；
- 禁止编造数据等限制。

可直接参考：

```text
研究目标：识别 BTC 永续合约中的拥挤交易、减仓与潜在反转风险。

分析步骤：
1. 对比资金费率当前值、历史分位与变化速度。
2. 检查持仓量（OI）与价格的同向或背离关系。
3. 结合多空爆仓数据判断杠杆出清方向。
4. 对互相冲突的信号进行交叉验证，不强行给出单边结论。

必须使用的数据：资金费率、持仓量（OI）、多空爆仓。
输出格式：结论、信号方向、置信度、关键价位、风险提示。
不得编造数据；数据缺失时必须明确说明。
```

### 第 3 步：可见性与创建

1. 复核名称、市场、模型、分析类型和提示词；
2. 第一次创建建议选择“私有”；
3. 提交后等待部署完成；
4. 到 `我的 AI → 分析师` 查看状态；
5. 等待它产生第一条有效观点，再考虑提供给策略使用。

### 创建完成后的检查

- Agent 是否显示为已部署或运行中；
- 最新观点是否按约定格式输出；
- 是否确实使用了指定数据；
- 数据不足时是否明确说明；
- 是否存在编造数据、过度肯定或输出跑题。

## 6. 创建 PM Agent（策略）

入口：`AI 策略` 或 `我的 AI → 创建策略`

创建向导会把用户选择组合成策略目标、风险规则和分析师信号源。当前界面通常包含六部分。

### Q1：选择策略目标

- **稳健保值**：低频，优先控制回撤；
- **波段交易**：捕捉区间波动；
- **趋势跟踪**：在趋势确认后顺势决策；
- **套利对冲**：关注资金费率、价差或对冲机会。

### Q2：选择风险风格

- **保守**：较低杠杆和仓位上限；
- **平衡**：在风险与机会之间取平衡；
- **激进**：更高杠杆及仓位上限，波动和亏损风险也更高。

第一次使用建议选择“保守”，并以页面显示的具体杠杆和仓位上限为准。

### Q3：选择交易标的

按页面可用范围选择主流标的、扩展标的或其他组合。处于“即将推出”状态的选项暂时不能使用。

### Q4：选择决策频率

- 较短周期：更新更及时，但更容易受短期噪声影响，消耗也可能更高；
- 较长周期：交易更少，但可能错过快速变化。

选择与策略本身匹配的周期，不要仅因为“更快”就选择最高频率。

### Q5：选择止盈止损

页面会提供不同盈亏目标组合。选择前应同时考虑：

- 策略交易频率；
- 标的波动；
- 杠杆；
- 单笔和总仓位上限；
- 可以承受的最大损失。

### Q6：生成策略

1. 检查目标、风险风格、标的、频率、止盈止损和分析师；
2. 点击“生成策略”；
3. 填写或确认策略名称、可见性和运行环境；
4. 第一次建议选择私有和模拟环境；
5. 提交并等待部署；
6. 到 `我的 AI → 策略` 查看状态。

### 新手建议配置

- 目标：稳健保值；
- 风格：保守；
- 标的：先选择一个熟悉的主流标的；
- 决策频率：使用向导中的中低频选项；
- 风控：必须启用明确止损；
- 可见性：私有；
- 环境：模拟；
- 分析师：先绑定 1–2 个逻辑清楚、信号互补的 Research Agent。

## 7. Fork 分析师或策略

Fork 的意思是复制现有 Agent 的结构，生成属于自己的版本。Fork 后的版本可以独立修改，不会直接改变原作者的 Agent。

### 操作步骤

1. 打开一个公开分析师或策略的详情页；
2. 先查看它的目标、数据、风险、表现和更新时间；
3. 点击“Fork”；
4. 根据页面提示确认可能产生的 Credits 消耗；
5. 修改名称、参数、提示词或可见性；
6. 提交创建；
7. 到“我的 AI”查看部署与运行状态。

### Fork 前必须注意

- Fork 不代表复制过去的收益；
- 原策略的风险参数未必适合你；
- Fork 后应重新检查标的、仓位、杠杆、频率和止损；
- 第一次运行建议使用私有与模拟方式；
- Fork 所需 Credits 以确认页实时显示为准。

## 8. Credits：余额、充值与消耗

### 8.1 查看余额

登录后，进入账户菜单或页面中的 Credits 入口，查看当前余额。实际入口名称与位置以当前界面为准。

### 8.2 充值

1. 打开 Credits 页面；
2. 点击“充值”或同义入口；
3. 选择页面提供的充值额度和支付方式；
4. 核对金额、获得的 Credits、支付网络及到账说明；
5. 完成支付；
6. 返回余额或账单页面确认到账。

不要向客服私下转账，也不要把密码、验证码、私钥或完整支付凭证发给任何人。

### 8.3 Credits 在哪里消耗

创建、Fork、运行 Agent 或使用特定模型/服务时，可能产生 Credits 消耗。具体项目、价格、计费频率和失败任务是否扣费，必须以操作确认页和账户账单为准。

### 8.4 充值后未到账

1. 刷新页面并重新登录；
2. 检查支付是否成功；
3. 检查是否使用了页面指定的网络、币种或支付方式；
4. 等待充值页说明的正常到账时间；
5. 仍未到账时联系官方客服，并提供：
   - Flowmax 账号邮箱；
   - 充值时间和金额；
   - 订单号或交易哈希；
   - 隐去敏感信息的页面截图。

不要提供密码、验证码、私钥或 API Secret。

## 9. 在“我的 AI”中管理 Agent

“我的 AI”通常分为“策略”和“分析师”两个标签。重点查看：

- 部署或运行状态；
- 当前运行环境；
- 决策周期；
- 使用的模型与分析师；
- 最新观点或决策；
- 每日及逐单盈亏；
- 当前持仓和杠杆；
- Credits 消耗记录。

### 启动和暂停

- 修改策略参数前，建议先暂停；
- 暂停后确认没有新的决策继续产生；
- 保存修改，再重新启动；
- 重启后检查新配置是否已经生效。

### 删除

删除前先确认：

- 是否仍有关联的运行任务；
- 是否需要保留提示词、策略配置或历史记录；
- 是否存在未处理持仓；
- 删除是否不可恢复。

不要把“暂停”当成“删除”，也不要在未确认持仓与执行状态时直接删除正在运行的策略。

## 10. 客服 FAQ

### Q1：Research Agent 和 PM Agent 有什么区别？

Research Agent 负责市场研究并输出观点；PM Agent 使用一个或多个研究信号，再结合策略和风控规则生成决策。简单说，前者负责“研究”，后者负责“管理策略”。

### Q2：我不懂编程，可以使用吗？

可以。创建向导会引导用户选择市场、目标、风险、频率等参数。第一次建议先 Fork 一个接近自己目标的 Agent，并用私有和模拟方式验证。

### Q3：创建后为什么一直显示部署中？

部署需要一定时间。先刷新页面并查看状态；若长时间没有变化，记录 Agent 名称、创建时间和页面截图后联系客服。不要重复快速提交，以免生成多个 Agent。

### Q4：分析师创建成功，但没有产生观点，怎么办？

检查部署状态、数据类型、提示词和数据是否可用。提示词应明确研究目标、数据来源和输出格式。若数据缺失，Agent 应明确说明，而不是编造观点。

### Q5：策略为什么没有产生新决策？

检查策略是否已启动、是否仍在部署、决策频率是否尚未到达、绑定分析师是否有新信号，以及 Credits 余额是否充足。

### Q6：Fork 后会和原策略完全一样吗？

不会。Fork 复制的是创建时可复用的结构或配置。之后的运行时间、市场环境、用户修改和风险参数不同，结果也会不同。

### Q7：Fork 会复制原策略的收益吗？

不会。历史表现不能被复制，也不代表未来结果。

### Q8：为什么我看不到某个市场或标的？

该市场可能尚未开放、处于灰度阶段，或不适用于当前账户和地区。以页面当前可选项为准。

### Q9：为什么创建或运行失败？

依次检查：

1. 必填项是否完整；
2. Credits 是否充足；
3. 选择的市场、模型和数据类型是否仍可用；
4. 提示词是否过长或包含不支持的内容；
5. 网络是否正常；
6. 页面是否提供错误信息。

联系客服时请附错误文字、发生时间、Agent 名称和截图。

### Q10：Credits 为什么减少了？

创建、Fork、运行 Agent 或调用特定模型/服务可能消耗 Credits。请先查看确认页和账户账单。若账单与操作不一致，向客服提供发生时间、Agent 名称和账单记录。

### Q11：充值支持什么方式？价格是多少？

以 Credits 充值页实时显示为准。支付方式、币种、套餐和价格可能调整，客服不应使用过期截图或口头价格作承诺。

### Q12：充值可以退款吗？

以充值页、服务条款和当地适用规则为准。在产品政策正式确认前，客服不要承诺退款结果。

### Q13：可以直接使用真实资金交易吗？

是否开放真实交易、适用地区和准入条件，以当前产品页面及服务条款为准。新用户应先在模拟环境验证策略，并充分理解风险。

### Q14：策略表现很好，是不是代表以后也会赚钱？

不是。历史收益、胜率和回撤只反映特定时间段和市场条件，不代表未来结果。AI Agent 的输出不构成投资建议。

### Q15：账号或资产安全出现问题怎么办？

立即停止相关操作，修改账户密码，撤销可疑登录或授权，并通过官方渠道联系客服。不要向任何人发送密码、验证码、私钥或交易所 API Secret。

## 11. 客服标准回复模板

### 创建或部署异常

> 已收到。请提供 Agent 名称、创建时间、当前状态和错误页面截图，我们会进一步排查。请勿连续重复创建，以免生成多个任务；也不要提供密码、验证码或密钥。

### Credits 未到账

> 请先确认支付状态及充值页标注的正常到账时间。若已超过该时间，请提供账号邮箱、充值时间、金额、订单号或交易哈希，以及隐去敏感信息的截图。请勿发送密码、验证码或私钥。

### Credits 扣费疑问

> Credits 的消耗项目与数量以操作确认页和账户账单为准。请提供发生时间、Agent 名称、相关操作和账单截图，我们会核对记录。

### 策略收益咨询

> 策略的历史表现不代表未来结果，请同时关注统计周期、回撤、仓位、杠杆和止损。Flowmax 的研究及策略输出不构成投资建议。

### 功能尚未开放

> 该功能目前可能尚未对当前市场、地区或账户开放，请以页面可选项为准。正式开放时间请关注 Flowmax 官方公告。

## 12. 使用安全与风险原则

- 先私有、后公开；
- 先模拟验证、后考虑其他运行环境；
- 使用明确的止损、仓位和杠杆上限；
- 修改配置前先暂停，修改后确认新配置已生效；
- 不向任何人提供密码、验证码、私钥、JWT 或交易所 API Secret；
- 不根据单一收益率或胜率选择策略；
- 历史表现不代表未来结果；
- AI Agent 的研究与策略输出不构成投资建议。
