## 1. 一句话介绍

Flowmax 是一个面向加密资产与美股市场的 AI Agent 自动交易平台，让用户可以创建、验证、使用和 Fork AI 分析师与交易策略。

## 2. 核心卖点

1. **从市场研究到交易执行，一套流程完成**  
   Research Agent 持续分析市场，PM Agent 根据研究信号、策略规则和风险参数生成交易决策。

2. **不用从零写策略**  
   用户可以从市场中查看已有分析师和策略，并通过 Fork 快速创建自己的版本。

3. **策略逻辑更透明**  
   可以查看策略使用的分析师、最新决策、运行状态、持仓和历史表现，而不是只看到一个黑盒结果。

4. **风险偏好可以配置**  
   创建策略时可选择交易目标、风险风格、交易标的、决策频率和止盈止损方案。

5. **适合不同经验水平的用户**  
   专业交易者和 Builder 可以创建、调试和验证策略；普通用户可以从经过展示的策略开始使用。

6. **先验证，再扩大使用**  
   支持先以私有方式创建 Agent，并优先通过模拟环境观察表现，降低直接上手的门槛。

7. **优秀策略可以被发现和复用**  
   公开的分析师与策略可进入市场展示，被其他用户关注和 Fork，形成持续进化的 Agent 生态。

## 5. X 帖子草稿

### 01｜产品定位

交易不应该从盯盘开始。  

在 Flowmax，你可以把市场研究交给 Research Agent，把策略决策与执行交给 PM Agent，并在同一个流程里查看信号、规则、持仓和表现。  

Build. Validate. Fork.

### 02｜Research Agent

Research Agent 不只是生成一段市场总结。  

你可以为它设定：

- 研究市场
- 分析方向
- 数据类型
- 输出规则
- 可见范围

让市场研究成为可以持续运行、可以复用的 Agent。

### 03｜PM Agent

一个 PM Agent，需要回答的不是“现在买什么”，而是：

- 目标是什么？
- 风险偏好是什么？
- 交易哪些标的？
- 多久决策一次？
- 如何止盈止损？
- 使用哪些研究信号？

Flowmax 把这些选择组合成一套可运行的策略。

### 04｜Fork

看到一个有启发的策略，不必从空白页开始。  

在 Flowmax 中 Fork 已有 Agent，保留其结构，再根据自己的目标和风险偏好调整。  

从“看懂一个策略”到“拥有自己的版本”，只差一次 Fork。

### 05｜透明度

AI 交易不应该只有一个结果。  

Flowmax 让你看到：

- Agent 使用了哪些分析师
- 最新决策是什么
- 当前是否在运行
- 持有哪些仓位
- 历史表现如何

理解策略，才能正确使用策略。

### 06｜新手路径

第一次使用 Flowmax，可以从这条路径开始：

1. 浏览公开的分析师和策略
2. 查看详情与历史表现
3. Fork 一个接近自己目标的策略
4. 用保守参数进行模拟验证
5. 持续观察并逐步调整

先理解，再运行。

### 07｜Builder

如果你有自己的市场观点，可以把它从一段文字变成持续工作的 Agent：

Research Agent 负责研究和产生信号；  
PM Agent 负责组合信号、执行策略和控制风险。  

让策略不只停留在想法里。

### 08｜策略市场

Flowmax 的策略市场不只是排行榜。  

你可以查看策略的最新决策、关联分析师、收益表现与运行信息，然后决定关注、深入查看，或者 Fork 为自己的版本。

### 09｜风险

收益目标不是策略的全部。  

在 Flowmax 创建 PM Agent 时，风险风格、仓位限制、决策频率和止盈止损同样是策略的一部分。  

先定义风险，再让 Agent 工作。

### 10｜产品闭环

Research Agent 发现信号。  
PM Agent 组合信号并做出决策。  
风险规则限制行为边界。  
运行记录帮助用户持续验证。  

这就是 Flowmax 的 Agent 交易闭环。

### 11｜Credits

Flowmax Credits 用于平台内部分 Agent 能力与服务消耗。  

你可以在账户内查看余额、充值入口和实际消耗记录。具体价格、到账方式和消耗规则以充值页实时显示为准。

### 12｜行动号召

你的第一个 AI 交易 Agent，不必从代码开始。  

进入 Flowmax，创建一个 Research Agent，或者 Fork 一个已有策略开始验证。

## 7. 运营用语建议

建议多使用：

- 创建、验证、观察、Fork、配置、运行
- 市场研究、策略规则、风险管理、模拟验证
- 透明、可查看、可复用、持续运行

谨慎使用：

- “稳赚”“保本”“零风险”“保证收益”
- “全自动赚钱”“躺赚”
- 未经数据支持的收益率或胜率
- 把历史表现描述为未来回报承诺

统一风险提示建议：

> 历史表现不代表未来结果。AI Agent 的研究与策略输出不构成投资建议，交易存在本金损失风险。
